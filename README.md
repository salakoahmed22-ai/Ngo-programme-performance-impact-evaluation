NGO Programme Performance & Impact Evaluation Dashboard

Project Overview

This project is a simulated NGO Monitoring & Evaluation (M&E) data analysis project focused on youth empowerment programme performance and beneficiary outcomes.

The project demonstrates how raw programme data can be cleaned, validated, analysed and transformed into useful M&E insights using Microsoft Excel.

Project Objectives

- Clean and validate beneficiary programme data
- Identify data quality issues and duplicates
- Analyse programme performance against targets
- Monitor beneficiary outcomes
- Analyse employment and income outcomes
- Develop an interactive M&E dashboard
- Present findings to support programme reporting and decision-making

Dataset

The dataset contains 629 raw beneficiary records, which were cleaned to 620 unique beneficiaries after identifying and removing 9 duplicate records.

The dataset covers programme participation, attendance, training outcomes, employment and income-related indicators.

Tools Used

- Microsoft Excel
- Power Query
- VBA
- Data Validation
- Pivot Tables
- Charts & Data Visualization

Workbook Structure

The Excel workbook contains:

1. Cover
2. Raw Data
3. Cleaned Data
4. Data Quality
5. M&E Analysis
6. Executive Dashboard
7. Programme Performance
8. Beneficiary Outcomes
9. Employment & Income
10. Indicator Reference
11. Automation Log

Key M&E Features

- Beneficiary data cleaning
- Duplicate identification
- Data quality checks
- Indicator tracking
- Target vs. actual analysis
- Programme performance analysis
- Beneficiary outcome analysis
- Employment and income analysis
- Executive dashboard
- VBA-assisted workbook automation

Key Learning

This project demonstrates the practical application of M&E and data analysis skills to transform programme data into structured information that can support monitoring, reporting and evidence-based decision-making.

Note:

This is a simulated portfolio project created for demonstration and learning purposes. The programme, organisation and beneficiary data are fictional.
